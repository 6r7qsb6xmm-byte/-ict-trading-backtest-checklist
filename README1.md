# ICT Trading Backtest Checklist

An open-source educational project that organizes an ICT-style trading setup into a clear and repeatable backtesting process.

## Purpose

Trading concepts are often presented across many videos and notes. This project converts those ideas into a structured checklist that can be tested consistently.

## Strategy overview

The setup uses:

- Higher-timeframe liquidity
- A liquidity sweep
- Lower-timeframe market structure shift
- Defined stop-loss placement
- Risk-based position sizing
- Session filters
- Trade journaling and review

## Current status

This project is in early development. The rules are being documented, tested and refined.

## Disclaimer

This project is for educational purposes only and does not provide financial advice.
